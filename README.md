# Market Selector Combinator

适用于 Factorio 2.1 的脚本型选择运算器。

## 使用

1. 研究“电路网络”，制造并放置“市场选择运算器”。
2. 在输入端接红线（库存信号）和绿线（生产需求信号）。
3. 点击运算器，选择“生产订单”或“超市订单”模式，再填写当前模式的参数。
4. 从输出端读取结果；红线和绿线均可使用。

每 10 tick 更新一次，仅处理正数物品需求。同一时刻只会选择一个产品：产品库存低于基础订单量，并且每种配方原料库存严格大于 `单份用量 × 材料需求倍率` 时，启动并锁定该请求；锁定后直到产品库存达到 `订单量 × (1 + 额外可生产倍率)`，或任一种原料库存严格小于 `单份用量 × 原料保留倍率` 时，才释放并选择下一个产品。产品输出数量实时使用 `订单量 × (1 + 额外可生产倍率) - 当前库存`，原料输出数量为单份用量乘材料需求倍率。两组不同的启动、停止阈值共同提供迟滞空间。

配方选择仅考虑当前势力已由科技解锁且所选机器可制造的配方；优先使用主产品匹配或与物品同名的配方。

“超市订单”会把绿线需求与红线库存的差额按配方逐层展开。当某个物品没有可用配方、达到递归深度上限，或库存已足够供应其全部配方原料时，递归在该物品停止并输出其生产数量。递归深度为 0 时不限制层数；多个需求会按稳定顺序共享并扣减本轮可用库存，避免重复占用。

## 代码结构

- `control.lua`：运行阶段入口，处理实体生命周期、电路信号、生产订单与超市订单算法，以及事件分发。
- `scripts/gui.lua`：独立 GUI 模块，只负责窗口创建、参数区域显隐、连接状态刷新和关闭行为；不直接读取 `storage`，也不参与生产计算。

代码中的 `---@param` 和 `---@return` 是 Lua Language Server 可识别的类型注释；普通中文注释会进一步解释对应 Factorio API 的用途和采用该设计的原因。

选择运算器本体的图标层会展示当前锁定的待生产产品；当前没有待生产产品时显示问号。图标使用独立渲染层，不会写入线路。
